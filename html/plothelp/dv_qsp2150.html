QSP2150 Plot Help

This plot shows a Biospherical QSP2150 PAR (photosynthetically active radiation) sensor on the glider's truck vs. depth, dive and climb shown separately.

What the glider records depends on the sensor's calibration mode (its W setting):

  • A - volts minus dark (net volts)
  • B - (volts - dark) / calibration factor: calibrated in air
  • C - (volts - dark) / (calibration factor × immersion): calibrated in water
  • D - raw volts

The mode and the calibration constants go in sg_calib_constants.m (qsp_mode, qsp_cal_factor, qsp_immersion, qsp_dark, qsp_units, calibcomm_qsp). tools/GetQSPConstants.py writes them from a selftest capture that has the sensor's settings.

  • With the mode and the constants it needs, the plot shows in-water PAR (qsp_PAR) on the bottom axis; the column as recorded is on the top axis - click it in the legend to show it.
  • With the mode only, the plot shows the column as recorded, in the mode's units (volts for A and D). Mode C is already in-water PAR.
  • With no mode, the plot still shows the column as recorded, with the units marked unknown.

The plot starts on a log scale - light falls off roughly exponentially with depth. The buttons switch the axes between linear and log. A log axis can't show zero or negative values, and calibrated darks scatter around zero, so switch to linear to see the deep values.

The line under the plot is calibcomm_qsp: the sensor's model, serial number and mode.

Shaded/overlay regions (when present) mark sample timeouts and the commanded sampling range for the instrument - see the sampling traces help.
